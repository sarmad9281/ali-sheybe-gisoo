# دمو فروشگاه گیسو بیوتی

یک سایت ایستا با HTML، CSS و JavaScript است و به سرور یا نصب وابستگی نیاز ندارد. همه عکس‌ها کنار فایل index.html هستند. تصاویر و محصولات نمونه‌اند؛ قیمت‌ها و امتیازها واقعی نیستند. تصویر 5.jpg لوگوی ارسالی شما و سایر تصاویر نمونه ساخته‌شده برای دمو هستند.

## پیش‌نمایش
فایل index.html را در مرورگر باز کنید. سبد خرید و علاقه‌مندی‌ها در مرورگر ذخیره می‌شوند و به هیچ سامانه‌ای متصل نیستند. ثبت سفارش و پرداخت واقعی وجود ندارد.

## انتشار روی GitHub Pages
1. وارد GitHub شوید و یک مخزن عمومی جدید بسازید؛ برای مثال `gisoo-beauty`.
2. محتوای داخل پوشه website (نه خود پوشه) را در ریشه مخزن آپلود کنید. فایل index.html باید در ریشه مخزن باشد. گزینه Commit changes را بزنید.
3. در مخزن به Settings → Pages بروید. در قسمت Build and deployment، گزینه Deploy from a branch را انتخاب کنید. شاخه main و پوشه /(root) را انتخاب و Save کنید.
4. چند دقیقه صبر کنید. آدرس نهایی در همان بخش Pages نشان داده می‌شود و معمولاً شبیه `https://USERNAME.github.io/gisoo-beauty/` است. به جای USERNAME نام کاربری واقعی گیت‌هاب شما قرار می‌گیرد.
5. لینک نمایش‌داده‌شده را برای کارفرما بفرستید. برای مخزن خصوصی، دسترسی به Pages به پلن حساب گیت‌هاب بستگی دارد.

## تغییر محتوا
- نام، قیمت، دسته و عکس محصولات در ابتدای script.js قابل ویرایش است. قیمت‌ها به تومان هستند.
- متون صفحات در index.html و رنگ‌ها و ظاهر در style.css هستند.
- برای عوض کردن عکس‌ها، فایل هم‌نام را جایگزین یا نام فایل جدید را در HTML و JavaScript اصلاح کنید.
- برای نسخه عملیاتی، لازم است موجودی واقعی، راه‌های ارتباطی، شرایط فروش و اتصال امن به سامانه سفارش و پرداخت اضافه شوند.
